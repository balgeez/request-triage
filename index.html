What should get built first?

Every team has more tool requests than builders. This ranks a backlog by how manual, stale and error-prone each item is, how many teams it touches, and how hard it is to build. Change a number or a weight and the order updates.

How much does each factor matter?

Weights apply to the pain score.

Rate each 1 to 5. Effort is shown under each name.

The roadmap this produces

Top three go Now, the next three go Next, the rest wait. Small builds ship directly; bigger ones get a written spec for an engineering partner.

How the score works: pain is the weighted sum of manual, stale and error-prone ratings. Impact is pain times the number of teams affected. Priority is impact divided by effort, scaled to 100. A request with effort 1 or 2 is tagged "build directly"; effort 3 or more is tagged "write a spec". It is deliberately simple so a stakeholder can follow the reasoning. Built by Baljeet Singh.
